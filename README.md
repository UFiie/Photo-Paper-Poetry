# Photo Paper Poetry · 纸上续景

**Where photography ends, poetry begins.**

把一张真实照片的故事，延续到一页留白的纸上。

`photo-paper-poetry` 是一个以 **实拍照片 × 纸张留白 × 连续视觉隐喻 × 微型人物叙事** 为核心的图像创作 Skill。它不是简单把照片和插画上下拼接，而是寻找照片中一个真实存在的元素，让它越过画面中线，在纸张上继续生长、滴落、延伸或转化，并与小小的人物发生一段诗意的互动。

> 一半是真实的世界，一半是尚未写完的想象。

## ✨ 作品特征

- **2:3 竖版艺术海报**：摄影与中性暖白艺术纸基本各占一半。
- **优先保留原照**：尊重原图物体、人物、光影、透视、颜色和摄影质感。
- **自然的跨界衔接**：花枝、树干、水流、道路、光线或绳索从照片真实位置延伸到纸面。
- **一个微型故事**：人物极小，动作自然，与延伸元素有明确的接触或因果关系。
- **材质不限于线稿**：真实树皮、花瓣、透明滴水、轻盈铅笔线和少量淡彩可以自然共存。
- **留白与诗句**：以大面积安静纸面和一条小字号英文旁白收束情绪。
- **每张独立构思**：不固定使用滴水、梯子、垂钓等模板。

## 🚀 使用方式

### 方式一：在支持 Agent Skills 的环境中使用

将本项目文件夹放入你的 Skill 加载目录，并确保 `SKILL.md` 位于名为 `photo-paper-poetry` 的文件夹内。例如，在支持该目录约定的 Codex 本地环境中：

```bash
# 在本机克隆到 Codex 的用户级 Skills 目录
mkdir -p ~/.codex/skills
git clone https://github.com/UFiie/photo-paper-poetry.git ~/.codex/skills/photo-paper-poetry
```

随后上传一张实拍照片，并输入：

```text
按 photo-paper-poetry Skill 处理这张照片。
```

也可以附加偏好：

```text
按 photo-paper-poetry Skill 处理这张照片。
保留原照片的真实光影，让树枝自然延伸到下半张纸；
微型人物动作要有创意，不要出现梯子；英文文案尽量简短。
```

**注意：** 是否自动发现和执行 GitHub 中的 Skill，取决于你使用的具体客户端及其配置。只提供一个 GitHub 链接，不代表所有 ChatGPT 网页对话都会自动安装或加载它。可在支持的工具中安装本仓库，或将 `SKILL.md` 内容提供给当前会话。

### 方式二：直接使用 `SKILL.md` 的创作指令

如果平台没有原生 Skill 加载功能，可以将 [`SKILL.md`](./SKILL.md) 提供给具有图片生成/编辑功能的 AI，并上传照片，要求它按照文档执行。

Skill 是创作指令，不是独立图像模型；要真正输出图片，仍需要当前环境拥有图像生成、编辑或合成能力。

## 🖼️ 五种参考创意方向

以下是创作逻辑示意，而非需要重复生成的模板。实际作品应根据新照片重新选择“真实来源 → 纸面延伸 → 微型动作”。

| 摄影内容 | 跨界元素 | 纸面叙事 |
| --- | --- | --- |
| 雪山与森林 | 山中融雪越界，化作一串冰滴与小水潭 | 微型人物接水、观察与垂钓 |
| 傍晚湖畔树林 | 一段真实树干越过分界继续向下生长 | 攀爬者与拉绳的人彼此配合 |
| 日落湖面 | 湖水变成缓慢下坠的透明液流 | 小小工人借助工具承接水流 |
| 建筑与绿树 | 一条带叶的树枝继续延伸到纸上 | 人物在枝上劳作、收集与照料 |
| 春日盛开的花 | 一串真实花枝延入纸面，花瓣零星飘落 | 小园丁用极细的工具接住春天 |

这些方向的共同点不是某个固定元素，而是：**源于照片、连续跨界、有互动、有余白、有隐喻**。

## 🎨 可调整的创作偏好

Skill 会自行判断照片适合的方案。也可以在使用请求中指定：

| 可调整项 | 默认倾向 | 示例 |
| --- | --- | --- |
| 画幅 | 2:3 竖版 | `保持 2:3` |
| 上下比例 | 约 50% / 50% | `照片占 52%，下方纸面占 48%` |
| 照片保留 | 优先原图、最少裁切 | `尽量保留整个建筑` |
| 连接物 | 由原片中真实元素决定 | `让右侧的树枝跨过边界` |
| 下半风格 | 真实材质 + 少量线绘/淡彩 | `人物全部用细钢笔线表达` |
| 微型人物 | 1–2 位，极小比例 | `只出现一个提着水桶的人` |
| 英文旁白 | 8–18 个单词，小字号 | `仅用 4 个词，放在左侧` |
| 禁用元素 | 避免刻板模板 | `不要用梯子、钓鱼竿或绳索` |

## ✅ 判断作品是否成功

一张合格的作品应同时满足：

1. 上半的照片仍然一眼认得出是用户上传的那张。
2. 至少一个关键元素从照片**准确、连续地**进入纸面，而非凭空开始。
3. 小人物不是贴纸：动作与跨界元素存在清楚的联系，身体有支撑点。
4. 下半有大量干净留白，没有被新风景、复杂速写和装饰占满。
5. 诗句轻而小，增强氛围而不抢占视觉中心。
6. 换一张照片就能诞生一个新的连接想法，不会千篇一律。

## ⚠️ 关于“100% 保留原照片”

Skill 将源照片完整性设为最高优先级，但**纯生成式模型通常无法保证逐像素不变**。

如果你需要真正的像素级保真，推荐使用：**原照片裁切与图层锁定 → 仅生成或绘制跨界元素及下半部 → 将原照精确合成回摄影区域 → 单独排版英文文字**。在只有 AI 生图能力的情况下，目标是尽可能高的视觉一致性，而不是宣称已做到无损复刻。
